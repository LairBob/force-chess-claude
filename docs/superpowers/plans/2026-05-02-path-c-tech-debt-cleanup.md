# Path C Tech-Debt Cleanup — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate accumulated tech debt and stale process scaffolding before Phase 3 begins, with no functional change to gameplay. Migrate `react-chessboard` v4 → v5, delete dead code, replace bureaucratic process docs, harden the chess-rules test suite, and extract `App.tsx`'s growing inline JSX into focused components.

**Architecture:** Nine work buckets executed in four phases. Phase 1 dispatches three background agents in isolated git worktrees (largest independent buckets) concurrently with main-session deletions and config edits. Phase 2 merges worktree branches. Phase 3 does the sequential dependent work (App.tsx extraction, coverage rebaseline). Phase 4 is the verification gate.

**Tech Stack:** React 19, TypeScript 5.9 (strict), Vite 7, Vitest 4, Tailwind 4, chess.js 1.4, react-chessboard 5.10 (after migration), Playwright 1.57.

**Spec:** `docs/superpowers/specs/2026-05-02-path-c-tech-debt-cleanup-design.md`

---

## Conventions for the executor

- All paths are absolute Windows paths (`C:\dev\force-chess-claude\...`) since the project is on Windows. Use forward slashes inside POSIX-y commands and backslashes in PowerShell.
- Run all `npm` commands from the project root `C:\dev\force-chess-claude`.
- Each bucket gets one commit unless explicitly split. Commit messages follow the existing `[Phase N]: subject` style or `chore(scope):` for non-phase work.
- For background agent dispatch, use the `Agent` tool with `isolation: "worktree"`. The agent returns a worktree path and branch name; merge the branch into `main` after verifying the agent's report.
- For merge conflicts, prefer the worktree's version for files it owned exclusively. Hand-merge any genuine overlap.
- After each bucket, run `npm run typecheck` as a quick sanity gate.

```tsx
import type { Move } from '../../modules/chess-engine'

interface MoveHistoryProps {
  history: Move[]
}

export function MoveHistory({ history }: MoveHistoryProps) {
  if (history.length === 0) {
    return (
      <div data-testid="move-history" className="bg-gray-800 rounded p-2 max-h-48 overflow-y-auto">
        <p className="text-gray-500 text-sm">No moves yet</p>
      </div>
    )
  }

  const rows: { number: number; white: string; black: string }[] = []
  for (let i = 0; i < history.length; i += 2) {
    rows.push({
      number: Math.floor(i / 2) + 1,
      white: history[i].san,
      black: history[i + 1]?.san ?? '',
    })
  }

  return (
    <div data-testid="move-history" className="bg-gray-800 rounded p-2 max-h-48 overflow-y-auto">
      <div className="text-sm font-mono">
        {rows.map((row) => (
          <div key={row.number} className="flex gap-2">
            <span className="text-gray-500 w-8">{row.number}.</span>
            <span data-testid={`white-move-${row.number}`} className="w-16">{row.white}</span>
            <span data-testid={`black-move-${row.number}`} className="w-16">{row.black}</span>
          </div>
        ))}
      </div>
    </div>
  )
}
```
